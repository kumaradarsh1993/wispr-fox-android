# Android revamp plan (November 2026)

Source: Adarsh's 03-Nov brief, kept word for word in `../wispr-fox/docs/briefs/2026-11-03 brief - sync check and Android revamp.md`.

> **In short:** the app's main job is now turning Voice Recorder files into transcripts. Dictation into other apps stays, but becomes something you switch on when you want it. Every screen gets smaller type and fits on one S23 Ultra screen without scrolling.

## 1. Dictation into other apps becomes opt-in

**In short:** banking apps warn because of the accessibility service, not only the floating fox. The fix has to turn the accessibility service off, not just hide the fox.

What happens today:
1. Opening wispr-fox starts the floating fox (`MainActivity.onResume` starts `OverlayService` when `overlayBubbleEnabled`, which defaults to on).
2. The accessibility service (`WisprFoxAccessibilityService`) also starts the fox whenever it connects. While it runs, the fox appears whenever a keyboard is on screen, including inside banking apps.
3. Banking apps such as ICICI iMobile check whether any accessibility service that can read the screen is switched on, and whether another app is drawing over them. Either one triggers their warning.
4. The fox shows "on some fields and not others" because it follows a guess about whether the keyboard is visible (`KeyboardHeuristics`). Samsung's keyboard sometimes leaves an empty keyboard window open, and some apps never report focus changes.

The change:
1. A single **"Dictate into other apps"** switch at the top of Speak, off by default.
2. **Off** means:
   - the fox service is stopped;
   - the accessibility service turns itself off with `disableSelf()`, so the system no longer lists it as on;
   - nothing is drawn over other apps, which is what stops the banking-app warnings.
3. **On** means:
   - if accessibility is off, the app opens the accessibility settings page with one line explaining why;
   - the fox then shows with the keyboard as today.
4. The fox never shows over a known list of banking and payment apps (ICICI, HDFC, SBI, Axis, Kotak, Paytm, PhonePe, Google Pay, CRED), even when the switch is on.
5. The Quick Settings tile and the home-screen widget keep working with the switch off. They record and copy to the clipboard, and don't need the fox.

## 2. Leaner look

**In short:** text sizes drop by about 10 percent (1 to 2 sp), icons and buttons get smaller, and padding gets tighter.
1. Material type scale × 0.9 (body 16 → 14.5 sp, label 14 → 12.5 sp, title 22 → 20 sp).
2. Default icon size 24 → 20 dp. List rows get 12 dp of vertical padding instead of 16 dp.
3. Touch targets stay at least 40 dp so they're still easy to hit with a finger.

## 3. Bottom bar

**In short:** Speak, Upload, History, Settings. Conversations folds into History as a filter. Usage stays inside Settings.

## 4. Speak

**In short:** one fixed screen with no Recent list.
1. The big Tap to speak button, with the "Dictate into other apps" switch beside it.
2. A **quick settings** strip: engine and model chips for transcription and cleanup, readable at a glance, tap to change.
3. The Finish setup banner only appears when something is missing.

## 5. Upload

**In short:** one screen with three presets, your newest recordings ready to pick, and the options below.

```
┌───────────────────────────────────────────┐
│ Upload                         [📁 Files] │
│ Recent recordings                         │
│ ☐ Voice 031 · 32 min · 14:05             │
│ ☐ Voice 030 · 4 min · 11:20              │
│ ☐ Call with Asha · 18 min · yesterday    │
│                                           │
│ [ Transcript ] [ Meeting ] [ Custom ]     │
│ ─────────────────────────────────────     │
│ Transcribe  [Groq ▾]   [Whisper v3 ▾]     │
│ ☐ Label speakers                          │
│ Outputs  ☐ Clean  ☐ Draft  ☐ Notes [▾]    │
│                                           │
│ [        Transcribe 1 recording        ]  │
└───────────────────────────────────────────┘
```

1. **Recent recordings:** the 3 newest audio files in the recordings folder, tick one or several. The folder defaults to Samsung Voice Recorder (`Recordings/Voice Recorder`). You can change it in Settings, which asks once for access to the folder.
2. **Files** button, top right: the system file picker, for anything else.
3. **Presets:**
   - **Transcript:** Whisper Large v3 on Groq, no cleanup. For long voice notes to yourself.
   - **Meeting:** Deepgram Nova-3 for speakers plus Whisper Large v3 for wording, both kept. "Include Whisper version" is ticked by default.
   - **Custom:** Whisper with cleanup on by default. Every option can be changed.
4. **Options below the presets:** the presets fill them in, and changing one switches the preset to Custom.
   - Provider and model dropdowns sit side by side.
   - Ticking **Label speakers** switches to Deepgram Nova-3 and shows one line saying so.
   - **Outputs:** Clean transcript, Draft, Meeting notes, with one model picker.
5. **Share from Voice Recorder** opens a small sheet with 2 big buttons, **Transcript** and **Meeting**, plus "More options", which opens Upload with the file picked.

## 6. Copying a meeting

**In short:** one clipboard copy holds both versions, clearly labelled.
```
Transcript with speakers (Deepgram Nova-3)
Asha: ...
Adarsh: ...

──────────

Same audio, transcribed by Whisper Large v3 (no speaker labels, usually more accurate wording)
...
```
Speaker names change only the first part.

## 7. Copied audio

**In short:** copies are deleted once a recording is done with, and Settings shows what's left.
1. Shared and picked files are copied into the app so Android can't take back access mid-job. The staged copy is deleted once it has been converted to compressed audio.
2. **Settings → Storage** shows the space used by kept audio and by leftover copies, with a button to delete each.

## 8. History

**In short:** small actions on one row, a Refresh button, and an honest Rerun.
1. On an open card, **Copy**, **Read** and **Rerun** become small icons on the same row as the Raw / Clean / Draft tabs, with no second Copy button.
2. A **Refresh** button at the top runs the full sync check (`SyncEngine.reconcile`) and shows a one-line result.
3. Rerun greys out Transcribe and Label speakers when the audio isn't on this phone, with the line "Audio for this note is on another device." Before the sync fix, the phone's own rows lost their audio link after syncing, which is why these looked grey even for phone recordings.
4. Card text is 1 sp smaller.
5. Reading mode leaves room at the bottom so the last lines aren't hidden behind the bar.
